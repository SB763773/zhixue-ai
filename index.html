20.2 数据的波动程度

人教版 · 初二下册 · 数学 · AI生成于 2026-07-25

知识点精讲

1. 方差的定义：设有 n 个数据 x₁, x₂, ..., xₙ，各数据与它们的平均数 x̄ 的差的平方的平均数，叫做这组数据的方差，记作 s²。
2. 方差公式：s² = [(x₁ - x̄)² + (x₂ - x̄)² + ... + (xₙ - x̄)²] / n
3. 方差的意义：方差是用来衡量一组数据波动大小的量。方差越大，数据的波动越大，越不稳定；方差越小，数据的波动越小，越稳定。

重难点标注

重点：理解方差的概念，掌握方差的计算方法，能运用方差分析数据的波动情况。

难点：在实际问题中，能根据方差的大小做出合理的判断和决策，理解方差与数据稳定性的关系。

易错点总结

易错1：计算方差时，容易忘记先求平均数，直接用原始数据计算。切记：第一步永远是先算平均数 x̄。
易错2：混淆方差与标准差。标准差是方差的算术平方根（s = √s²），二者都衡量波动大小，但单位不同。
易错3：方差为0不代表数据没有意义，而是说明所有数据都相等，完全没有波动。

典型例题

例题：甲、乙两名射击运动员各射击10次，命中环数如下：

甲：9, 8, 10, 7, 9, 8, 10, 9, 7, 8    乙：8, 9, 9, 8, 9, 8, 9, 8, 9, 8

问哪位运动员的成绩更稳定？

AI解析思路：比较稳定性 → 计算方差 → 方差小的更稳定。
甲平均数 x̄甲 = 8.5，乙平均数 x̄乙 = 8.5
s²甲 = [(9-8.5)²×3 + (8-8.5)²×3 + (10-8.5)²×2 + (7-8.5)²×2] / 10 = 1.05
s²乙 = [(9-8.5)²×5 + (8-8.5)²×5] / 10 = 0.25
因为 s²乙 < s²甲，所以乙的成绩更稳定。

A

B
乙机床的次品数波动更大
C

D
无法比较
正确答案：A

AI分步解析

第一步 - 求平均数：x̄甲 = 4/7 ≈ 0.571，x̄乙 = 4/7 ≈ 0.571
第二步 - 求方差：
s²甲 = [(0-4/7)²×4 + (1-4/7)²×2 + (2-4/7)²×1] / 7 ≈ 0.531
s²乙 = [(0-4/7)²×3 + (1-4/7)²×4] / 7 ≈ 0.245
第三步 - 比较：s²甲 > s²乙，甲机床次品数波动更大。选A。

3. 某工厂甲、乙两个车间各有10名工人，其日均产量（件）如下：
甲车间：8, 9, 10, 10, 11, 11, 12, 12, 13, 14
乙车间：7, 9, 9, 10, 10, 11, 11, 12, 13, 15
(1) 分别计算两个车间日产量的平均数和方差；
(2) 从稳定性的角度分析，哪个车间更适合承担精密加工任务？
参考答案

AI分步解析

(1) 计算平均数：
x̄甲 = (8+9+10×2+11×2+12×2+13+14)/10 = 110/10 = 11（件）
x̄乙 = (7+9×2+10×2+11×2+12+13+15)/10 = 107/10 = 10.7（件）

一次函数 y = kx + b 的图像不经过第二象限，则 k 和 b 的取值范围是（　　）
你的答案：A（k>0, b>0）　正确答案：B（k>0, b<0）
AI诊断
错误类型：审题错误。「不经过第二象限」意味着图像只经过第一、三、四象限或第一、三象限。
经过一、三象限 → k > 0；不经过第二象限 → b ≤ 0。题目选项中最接近的是 k > 0, b < 0。

记忆口诀：k正过一三，k负过二四；b正向上移，b负向下移。
